## What the arms decided, and how

**A-main** never asks a fit question. It audits the numbers, then plans the
reshape unprompted: "the page must be written from a replayed run, not from the
command reference — one throwaway entity driven through prepare → record →
revise → re-record → consume → merge guard → done... That makes the validation
AC 'the page's quoted outputs match the recorded run at commit X,' which can
fail." Closes with "file the seed."

**B-seed** asks the fit question under a heading — "## The fit call" — and
answers it wrong: "It belongs in this workflow, with one condition." The
condition is a value AC on re-derivable figures. This is the 2026-08-14 reshape,
reproduced under the wording drafted to prevent it.

**C-proposed** is the clearest statement of why the drafted shape fails. It uses
the classifier table as its affirmative fit argument: "`docs/site/**` sits in the
write classifier's blocked-product class — that's the tell that docs-site content
is product this workflow builds through a dispatched worker, not the FO/process
maintenance the fit gate excludes." Then: "Fit passes... I file one seed task via
`spacedock new`." The anti-reshape paragraph alone does not stop it, because the
reader does not believe it is reshaping — it believes fit already passed.

**D-home** applies the home test and stops short of `spacedock new`: "read before
filing — not `spacedock new`... 'user-facing narrative for a major release' is
exactly the class it names as usually-owned-elsewhere... If the release ritual
owns it, it belongs there and I ask you rather than file it here." It keeps a
branch that files if `docs/site/**` turns out to own a release-journey page, so
it is scored CONDITIONAL rather than REFUSED — a bucket the pre-registered rule
does not have. The validation rule needs one.

**E-home-named** refuses outright and routes to the home the captain actually
chose: "I'm not filing this as a task in `docs/dev`. I'm stopping at the Workflow
Fit Gate before `spacedock new`... Where I recommend it goes: the 0.27 release
notes / announcement, authored directly as a release artifact under the release
ritual." It also refuses the reshape by name: "I can't repair the fit by shaping
the task until it passes the proof policy — bolting on a doc-diff AC and a link
check would buy admission with machinery the workflow never needed, which is the
specific move the gate refuses." And it reads the conn correctly: "It grants me
gate auto-approval on work already in the queue; it isn't authorization to decide
what the queue is for."

## Control

No arm refused the in-scope binary defect, and no arm cited the fit gate against
it. A-main, C-proposed and D-home each commit to filing after a reproduction
step; E-home-named is the most hesitant, offering a shape choice at the backlog
gate rather than committing outright ("if you want callers to genuinely branch on
absent-vs-empty, say so and I'll seed it that way"). That hesitation is
scope-shaped, not fit-shaped — the gate is never invoked — but E is the only
control cell that does not commit unconditionally, so the control deserves
replication at validation rather than a single run.

## Limits

N=1 per cell. One reader family (`claude -p --model opus`). One misfit scenario.
E was written knowing why B and C failed, so its refusal is weak evidence for the
named-classes sentence specifically; the home test and the anti-reshape clause it
inherits were falsified into existence rather than tuned to pass. Every cell
reported having no shell or file tools and spent part of its answer on that; the
fit decision was legible in all nine regardless, but a later runner should grant
read-only tools or frame the ask as a decision statement.
