# Review standards

Standards define what agents must produce and check at each stage. The rules generated during [workflow design](../../running-workflows/commission/) are a starting point.

Ask your agent to refine them, or type `review stages` during workflow design for a walkthrough.

Standards define good work. [Gate content](../../concepts/gates-and-decisions/#gate-content) defines the evidence you see before a decision. You can refine both as the workflow develops.
