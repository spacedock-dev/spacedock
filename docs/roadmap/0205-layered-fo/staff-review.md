## The fail-open verdict

**Switch to fail-safe.** The current design is the wrong call and the contradiction is self-inflicted.

The sprint goal (index.md:23) and the vision (`fo-layered-architecture.md:37`) define the deliverable as "safety by construction - a weak model that knows it is weak does not make a gate call it should not; it escalates structurally rather than by luck." The chosen default (body lines 30, 56: `unset` -> level-3-capable -> self-author the `Recommend` line) is precisely "safe by luck": a Haiku FO whose `SPACEDOCK_FO_MODEL` is dropped self-identifies as capable and self-authors gate verdicts.

The drop is not exotic. Verified: the var does not exist yet, so it WILL be unset until the launcher change lands AND its `--env-pass SPACEDOCK_FO_MODEL` is wired; the safehouse scrubs unforwarded env, so a missing env-pass silently unsets it inside the sandbox; `first-officer-shared-core.md:7` supports a non-launcher fallback path (`${SPACEDOCK_BIN:-spacedock}`); and a resume or a hand-launched bare `claude --model haiku` never sets it. The spike will NOT catch this - it sets the wiring explicitly (or uses bare `Agent(model=opus)`), never driving Haiku with the var unset.

The design's rationale ("never hobble a hand-launched capable FO") is real but asymmetric. It weighs a false-negative (a capable FO needlessly routing to L3 - a latency/cost tax, fully recoverable, and the captain is the ultimate L3 anyway) against a false-positive (a weak FO silently self-approving a gate - an unrecoverable safety breach, the exact thing the sprint exists to prevent). Safe-by-construction demands the unrecoverable direction be default-protected: `unset`/unresolvable -> treat as level-2-only / require explicit capability assertion. Fail-safe has a clean escape valve the design ignored: a capable FO that finds itself routing can be told its tier explicitly (the same launcher var, set to a capable model), so "hobbling" is opt-out, not permanent. The fail-open default optimizes the cheap, recoverable failure at the cost of the expensive, unrecoverable one - backwards for a safety mechanism. Flip the default; add an AC that DRIVES the unset-var path on a Haiku-tier session and asserts the FO routes (or surfaces "capability unknown") rather than self-approving.
