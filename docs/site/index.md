# Welcome

Your agents finish work faster than you can judge it. **Your judgment is the bottleneck, and Spacedock is built around it.**

## Who it's for

You hand agents whole chunks of work and run several sessions at once, in Claude Code or Codex. You may build your own skills, or use agents beyond code: email, research, content, go-to-market.

## Install

One command installs Spacedock.

```sh
brew install spacedock-dev/tap/spacedock [TBD]
```

Until one install ships, install Workflow on its own: see [Install](get-started/install.md).

## One problem, three places

The bottleneck shows up in three places. Each Spacedock feature takes one. Open the one that fits.

| When this happens | Use | Open it | What it does |
| --- | --- | --- | --- |
| An agent's work is waiting for your call | **[Review](review/index.md)** | `[command TBD]` | Opens the work beside your session, in the terminal or the browser. You comment on the exact line, and the agent revises from your comments. You can send it to a colleague for a second opinion. |
| An agent may have left the goal you agreed on | **[Compass](compass/index.md)** | `[command TBD]` | Shows the goal beside what each session is doing, so the one that has left it stands out. |
| Every call comes to you, and only some need your judgment | **[Workflow](workflow/index.md)** | `[command TBD]` | You write down once what good looks like at each step. Only the calls that need you reach you, with the evidence attached. |
