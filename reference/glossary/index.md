# Glossary

## Workflow

Stages, standards and decision points for a recurring type of work. See [Workflows and entities](../../concepts/workflows-and-entities/).

## Entity

One work item and its progress record. See [Workflows and entities](../../concepts/workflows-and-entities/).

## Stage

A step with defined work and standards, such as design, implementation or review. See [Stage lifecycle](../../concepts/stage-lifecycle/).

## Gate

A checkpoint that requires a decision before work continues. See [Gates and decisions](../../concepts/gates-and-decisions/).

## Gate content

The context and evidence presented at a decision point. See [Gate content](../../concepts/gates-and-decisions/#gate-content).

## First officer

The agent that coordinates workers and brings decisions to you. See [The operating model](../../concepts/operating-model/).

## Ensign

A worker agent assigned to a stage. See [The operating model](../../concepts/operating-model/).

## Mod

An extension that adds workflow behavior without adding a stage. See [Mods and standing teammates](../../advanced/mods-and-standing-teammates/).

## Standing teammate

A specialist agent available throughout a session. See [Mods and standing teammates](../../advanced/mods-and-standing-teammates/).

## Split-root state

Workflow records stored in a separate Git checkout from the code. See [Split-root state](../../advanced/split-root-state/).
