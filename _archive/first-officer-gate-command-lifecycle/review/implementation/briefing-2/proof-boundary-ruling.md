# Recorded lifecycle proof-boundary ruling

The end value remains unchanged: a gated stage cannot advance or dispatch without one validated and consumed authorization, every semantic lifecycle event is required, authority is durable, resume is one-use, and the procedure works across supported hosts.

The following verification mechanisms are binding:

1. Deterministic trace mutants delete each of the six semantic events and must deny successor dispatch.
2. A live copied-skill positive proves the runtime loaded the copied skill body and emitted the six-event lifecycle. A command-only prose deletion that the model semantically reconstructs is not required to fail; deleting additional authorization prose is prohibited because it no longer isolates the command.
3. The source-derived route extractor and per-route deletion controls cover every engage/resume route. One representative engaged live route per supported host proves the host binding; an all-routes-by-all-hosts live matrix is not required.
4. Claude must complete one credentialed positive run with copied-body provenance, six successful events, consume, real spawn, and correlated durable output.
5. Pi must wait for its returned async child handle to complete before grading or cleanup, then prove the same durable result.
6. Codex must prove the public live lifecycle and correlated durable child output. Its exact spawn/handle parser remains load-bearing through native-shape offline fixtures; an unexposed live public-stream handle is not required and private rollout archives are not accepted.
7. PR #561's `8n` projection must be present in the integration base before `6y` enters validation.

These changes correct the proof boundary; they do not narrow a value criterion, permit transcript-only evidence, remove an event, add production Go, or relax the existing byte/LOC ceilings.
