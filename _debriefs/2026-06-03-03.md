## Decisions

- **Codex worker completion notification:** the dogfood evidence supports "queued completion flush" but not autonomous idle wake. `gn` records a retryable probe so future Codex behavior changes can be re-tested.
- **FO scheduling rule:** finish the ready dispatch/advance/gate sequence first, then call `wait_agent` only when no other work remains. Foreground waits should be announced as interruptible and resumable.
- **Scenario model:** scenario is the durable natural-language spec; codified tests and LLM runs are executor implementations of the same scenario. Shared coverage should be `{claude,codex} x {codified,llm-live}`, with `model` separate from `mode`.
- **Cost ledger scope:** raw per-run live journey metric JSON artifacts in CI are the first proof. Aggregation and release ledgers remain checked consumers, not the core acceptance point for this slice.
- **Next cross-runtime scenarios:** prioritize PR lifecycle from workflow boot, then dispatch-before-wait, split-root bootstrap/resume, live metrics artifact capture, and feedback reuse boundaries. Codex-only probes stay out of the shared runtime scenario set.
